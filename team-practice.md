# Team Practice Notes

## Pull Request Workflow

- Pull the latest `main` branch before starting a new branch.
- Include testing notes in every pull request.
- Ask for review in the team Microsoft Teams channel when a PR is ready.

## Next notes

- Assign your review to a collaborator in github and inform them in our group-10 Microsoft Team channel.
- The assigned member who review the PR should comment for correction to fix in the PR or approval of the PR before merging into the `main` branch.
